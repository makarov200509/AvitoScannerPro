# AvitoScannerPro

Веб-инструмент для парсинга, поиска, мониторинга и анализа рынка на Avito.

## Возможности

- Поиск объявлений по всей России или конкретному городу
- Анализ рынка (медианная, средняя, минимальная и максимальная цена)
- Мониторинг новых объявлений с интервалом от 1 до 5 минут
- Режим "Перекуп iPhone" - быстрый выбор моделей iPhone
- Тёмная/светлая тема
- Мультипользовательская система
- История поисков и анализов
- Веб-уведомления

## Быстрый старт

### Предварительные требования

- Python 3.11+
- Node.js 18+ (для сборки фронтенда)
- Google Chrome (для Selenium)
